# MotionLog

Jednoduchý offline deník ručně zadávaných aktivit pro iOS 17+.

## Sestavení
1. Na Macu otevři `MotionLog.xcodeproj` v Xcode.
2. V Signing & Capabilities nastav svůj tým a případně změň Bundle Identifier.
3. Product → Archive → Distribute App a zvol odpovídající způsob distribuce/exportu IPA.

Projekt není v tomto prostředí zkompilovaný ani testovaný v Xcode. Záznamy jsou pouze ruční, nejsou propojené s Apple Health.
